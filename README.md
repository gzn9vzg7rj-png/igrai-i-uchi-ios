# Играй и учи

Bulgarian educational game for young children.

## Free iPhone version

The free installable web app is in `/docs` and is designed for GitHub Pages.

Features:
- Bulgarian interface and Bulgarian voice prompts
- Colors, shapes, animals, and mixed mode
- Cartoon animal characters
- Large fully tappable category cards and answer tiles
- Stars and celebration rewards
- Parent difficulty settings
- Offline support after first load
- No ads, account, analytics, or Apple Developer subscription required

### Install on iPhone

1. Enable GitHub Pages for this repository using `main` branch and `/docs` folder.
2. Open the published GitHub Pages URL in Safari.
3. Tap Share → Add to Home Screen.
4. Launch `Играй и учи` from the Home Screen.

The native SwiftUI/TestFlight files can remain in the repository for future use if an Apple Developer membership is added later.
